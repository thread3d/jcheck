# J0475 — DanglingDocComment

**Tier:** T2 flow · **Default level:** warn

## Why it matters

A `/** ... */` comment that is not attached to a declaration documents nothing: no tool reads it,
no IDE shows it on hover, and it usually means a member was deleted or moved without its doc. JDK 23
added `-Xlint:dangling-doc-comments` to name the leftovers.

## Failing example

```java
/** Returns the size. */
// (the method was removed)
public final class Bag {
}
```

## Fixed example

```java
public final class Bag {
    /** Returns the number of items in the bag. */
    public int size() {
        return 0;
    }
}
```

## Notes

- Move the comment to the declaration it was meant for, or delete it.
- A `/** ... */` block immediately before a declaration is fine; only unattached ones are reported.
- The lint is new in JDK 23, so the warning appears only when running on JDK 23 or newer.
