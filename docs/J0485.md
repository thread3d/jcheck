# J0485 — RestrictedTypeNamePreview

**Tier:** T2 (flow) · **Default level:** warn

## Why it matters

Some words are on deck to become restricted type names but are not reserved at any release yet.
javac warns when a declaration uses one of them as a type name, because raising the project's
release floor later can turn that declaration into an error. The warning is cheap to act on now
and impossible to act on after the upgrade breaks.

## Failing example

Compiled at a release floor where `record` is not yet a keyword:

```java
public final class Legacy {
    record Point(int x, int y) { } // at -source 8: "record" is a class name
}
```

```text
warning: 'record' may become a restricted type name in a future release
```

## Fixed example

```java
public final class Legacy {
    static final class Point {
        final int x;
        final int y;

        Point(int x, int y) {
            this.x = x;
            this.y = y;
        }
    }
}
```

Or raise the release floor to one where `record` is the actual feature — then this is a record
rather than a type named `record`.

## Notes

- The warning has no consequence today and is safe to ignore *only* while the release floor is
  pinned; treat it as a blocker for the next floor bump.
- Related: J0484 for names already restricted at the target release, J0131 when the construct
  itself is not yet supported.
