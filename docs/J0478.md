# J0478 — SunProprietary

**Tier:** T2 flow · **Default level:** warn

## Why it matters

`sun.*` and `com.sun.*` classes are internal implementation details of the JDK: they carry no
compatibility promise, they are closed off by the module system, and they can disappear in any
release. The `-Xlint:all` group warns as soon as one is referenced so the dependency is visible
before it breaks.

## Failing example

```java
import sun.misc.Unsafe;

final class Cache {
    private static final Unsafe UNSAFE = Unsafe.getUnsafe();
}
```

## Fixed example

```java
import java.lang.invoke.MethodHandles;
import java.lang.invoke.VarHandle;

final class Cache {
    private static final VarHandle HANDLE = MethodHandles.arrayElementVarHandle(int[].class);
}
```

## Notes

- The replacements are usually the supported API added for the same purpose:
  `java.lang.invoke`, `java.nio`, `java.lang.management`, `java.util.concurrent`.
- Some uses are genuinely unavailable through public APIs (deep reflection, foreign memory before
  the FFM API); those need `--add-exports` and a comment, not silence.
- `@SuppressWarnings("removal")` does not cover this lint; the suppression key is `sunapi`.
