# J1504 — UnnecessaryParentheses

**Tier:** T5 (rewrite) · **Default level:** note

## Why it matters

OpenRewrite's `org.openrewrite.staticanalysis.UnnecessaryParentheses` removes parentheses that do
not change precedence, such as `return (a + b);` or `if ((x))`. They add noise and, worse, suggest
a grouping that is not actually there, which is how a reader concludes `(a + b * c)` means something
it does not.

## What the change looks like

```java
// before
if ((x > 0)) {
    return (a + b);
}

// after
if (x > 0) {
    return a + b;
}
```

## Notes

- Parentheses that do change precedence, casts, and lambda parameter lists are left alone.
- The recipe is from `rewrite-static-analysis`; jcheck reports it as J1504 rather than a generic
  rewrite note so a diff that only tidies parentheses is easy to review.
- Run it alone with `jcheck rewrite`, or after the model fixes with `jcheck fix --rewrite`.
