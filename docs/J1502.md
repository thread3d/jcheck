# J1502 — FinalizeLocalVariables

**Tier:** T5 (rewrite) · **Default level:** note

## Why it matters

OpenRewrite's `org.openrewrite.staticanalysis.FinalizeLocalVariables` adds `final` to a local
variable that is assigned once and never reassigned. The declaration then records the read-only
intent and the compiler rejects a later accidental write. It is the rewrite counterpart of jcheck's
J0706.

## What the change looks like

```java
// before
int total = price + tax;

// after
final int total = price + tax;
```

## Notes

- Variables reassigned on any path, enhanced-for variables and try-with-resources variables are left
  alone by the recipe, matching J0706.
- Apply it with `jcheck rewrite` (recipe-only) or `jcheck fix --rewrite` (suggestions first, then
  recipes); both re-check and revert if the result gets worse.
- If the project prefers J0706, drop this recipe from `[fix] rewrite_recipes` and let `jcheck fix`
  handle it.
