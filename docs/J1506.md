# J1506 — CodeCleanup

**Tier:** T5 (rewrite) · **Default level:** note

## Why it matters

`org.openrewrite.staticanalysis.CodeCleanup` is a composite of the small, safe tidy-ups —
unnecessary parentheses, redundant modifiers, blank-line normalisation and similar. Applying it as
one recipe is how a project clears a backlog of style noise in a single reviewable pass.

## What it means

Because it is a composite, every change it makes is reported under J1506 and the note on each
diagnostic carries the recipe name `org.openrewrite.staticanalysis.CodeCleanup`. If a specific
change matters, run the constituent recipe by name instead so the code names it exactly.

## Notes

- Composites are convenient but coarse: the catalog row names the composite, not the individual
  rule, so a review should look at the file rather than rely on the code alone.
- jcheck applies recipes one at a time and reverts everything if the re-check gets worse, so a
  composite cannot leave the project in a state the checks reject.
- `CommonStaticAnalysis` is the larger sibling; list whichever the project wants in
  `[fix] rewrite_recipes`.
