# J0473 — RedundantCast

**Tier:** T2 flow · **Default level:** warn

## What it means

The cast does not change the type of the expression: it is already the target type, or it widens to
it. The cast adds noise and hides whether any conversion is happening at all, so javac's
`-Xlint:cast` reports it.

## Failing example

```java
Object value = "text";
String text = (String) value; // fine: Object to String is a real cast
String other = (String) text; // redundant: text is already a String
```

## Fixed example

```java
String other = text;
```

## Notes

- Remove the cast only when the expression's static type really is the target; a cast from a
  supertype is narrowing and is not reported.
- Generic casts that exist to satisfy a type inference are sometimes called redundant but are
  required; use an explicit type witness (`Foo.<Bar>of(...)`) instead.
- The warning appears with the `all` lint group that jcheck enables by default.
