# J0469 — ThisEscapeLocation

**Tier:** T2 flow · **Default level:** warn

## Why it matters

This is the location half of J0468: `-Xlint:this-escape` reports both a summary warning on the
constructor and a second diagnostic pointing at the exact expression that publishes `this`. The
location is the one to fix, and it is kept separate so the summary does not have to carry a span it
does not own.

## Failing example

```java
class Registry {
    Registry() {
        Registry.INSTANCE = this; // `this` escapes here before construction completes
    }

    static Registry INSTANCE;
}
```

## Fixed example

```java
class Registry {
    static Registry INSTANCE;

    static Registry create() {
        Registry registry = new Registry();
        INSTANCE = registry;
        return registry;
    }
}
```

## Notes

- Fix the expression this diagnostic points at; the summary warning (J0468) disappears with it.
- Both keys are in the `this-escape` group, so the two diagnostics from one constructor are not
  reported as unrelated findings.
- The lint needs JDK 21 or newer to run at all; on an older JDK the tier line says so.
