# J0257 — RestrictedTypeNameError

**Tier:** T1 (symbols and types) · **Default level:** error

## Why it matters

Once a release actually reserves a word as a type name, declaring a type with that name stops
compiling: the declaration is rejected rather than warned about. This is the error form of J0484,
and it is what a project sees the moment it raises its release floor past the reservation — code
that compiled at an older floor no longer does. The note under the error names the release that
reserved the word.

## Failing example

Compiled at a release that reserves `var`:

```java
final class var { // 'var' not allowed here: restricted type name as of release 10
    int x;
}
```

## Fixed example

```java
final class Var { // a name that is not reserved at any release
    int x;
}
```

## Notes

- Rename the type. There is no suppression: the declaration is not merely discouraged, it is not
  a legal type name at that release.
- The warning form (J0484) is the same information before the floor is raised, so a project
  watching for this error can be warned early by not suppressing J0484.
- The reserved set grows with releases (`var`, `yield`, `record`, `sealed`, `permits`), so a type
  name that is legal today is not guaranteed to stay legal.
