# J1501 — MissingOverrideAnnotation

**Tier:** T5 (rewrite) · **Default level:** note

## Why it matters

OpenRewrite's `org.openrewrite.staticanalysis.MissingOverrideAnnotation` adds `@Override` to a method
that overrides a supertype method. The annotation turns a rename or a mistyped parameter into a
compile error instead of a new, never-called method. jcheck's own J1301 reports the same thing, so
this code appears only when the recipe is run with the built-in pack disabled or when the recipe
finds something the pack did not.

## What the change looks like

```java
// before
public String greet(String name) {

// after
@Override
public String greet(String name) {
```

## Notes

- The recipe needs type attribution, which is why `jcheck rewrite` gives the runner the project's
  compilation classpath.
- jcheck's own fix for J1301 is equivalent; running both is harmless because the second sees it
  already done.
- Suppress the pair with `@SuppressJcheck(code = "J1301", reason = "...")`; a rewrite recipe is not
  suppressed in source, it is simply not in `[fix] rewrite_recipes`.
