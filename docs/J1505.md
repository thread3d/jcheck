# J1505 — EmptyNewlineAtEndOfFile

**Tier:** T5 (rewrite) · **Default level:** note

## Why it matters

A text file that does not end in a newline makes every POSIX tool that reads it treat the last line
specially: `diff` warns, `cat` glues the shell prompt to the code, and a patch that appends a line
has to rewrite the last one. OpenRewrite's `org.openrewrite.java.format.EmptyNewlineAtEndOfFile`
adds it.

## What the change looks like

```java
// before (no trailing newline after the closing brace)
public final class F { int x() { return 1; } }

// after
public final class F { int x() { return 1; } }
<newline>
```

## Notes

- This is a `rewrite-java` recipe rather than a static-analysis one, which is why it reports J1505:
  the runner works with any recipe on the resolved classpath, not just `rewrite-static-analysis`.
- It is safe to apply to every file, so it is a reasonable first recipe for a new project.
- The change is invisible in a rendered diff, so the code and the tier line are the audit trail.
