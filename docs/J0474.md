# J0474 — UncheckedMethodInvocation

**Tier:** T2 flow · **Default level:** warn

## Why it matters

Calling a generic method whose type argument cannot be inferred from the arguments produces an
unchecked invocation: the compiler picks `Object` and the result is a value whose type is not
actually verified. The failure surfaces later as a `ClassCastException`.

## Failing example

```java
static <T> List<T> listOf(Object o) {
    return List.of((T) o); // unchecked invocation: T is inferred as Object at the call site
}
```

## Fixed example

```java
List<String> names = Foo.<String>listOf(raw); // explicit type witness
```

## Notes

- Add the type witness at the call site, or change the method so the type argument is inferable from
  a parameter (`<T> List<T> listOf(T value)`).
- When the unchecked call is genuinely safe, `@SuppressWarnings("unchecked")` is the documented
  escape; a bare suppression is itself checked as J0003.
- The related unchecked-conversion warning is J0419; both are in the `unchecked` group.
